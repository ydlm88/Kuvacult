Questions

What is the first MCU movie in chronological order?

Captain America: The First Avenger. It is set during World War II, decades before Iron Man.

Should I watch the MCU in chronological or release order?

Release order keeps every reveal the way audiences first saw it. Chronological order follows the story timeline, which works well on a rewatch.

Does this list include the Disney+ shows?

There are two lists. The movies-only list uses @KVMCU. Scroll down to Movies + Disney+ series for the full timeline with every Marvel Studios series, live-action and animated, using @KVMCD.

Where do X-Men ’97 and Your Friendly Neighborhood Spider-Man fit?

They sit outside the main MCU timeline, so they’re at the end of the list. Watch them whenever you like.
