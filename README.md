# Kuvacult                                                                        
A collaborative watchlist platform for film lovers. Build shared lists with friends, log and review what you've watched, and settle on what to watch next with a real-time veto game — all synced live over WebSockets.

> **Check [Releases](../../releases) to download the latest build.**
---
## Features
- **Shared watchlists** — create lists, invite friends, and manage them together in real time
- **Reviews** — half-star ratings, written reviews, and likes. Follow friends, browse their profiles, and discover their public lists.  
- **Sacrifice** — every member picks films, the group vetoes until one survives
- **Live sync** — all watchlist changes broadcast instantly over WebSockets; no refresh needed
- **Séance** — screen-share a watch session with friends via WebRTC (LiveKit)
- **Letterboxd import** — drop in a Letterboxd ZIP or CSV export to migrate your watched history, reviews, and even lists.
